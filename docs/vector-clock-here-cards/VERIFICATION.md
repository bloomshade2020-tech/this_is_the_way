# VECTOR 時刻・HERE入力・HOME矢印の修正記録

2026-10-21。画面側の公開用変更記録。

## 変更範囲

- 画面側：保存日時・履歴ラベルをJSTへ統一。HERE入力は56pxから必要な分だけ拡張し、最大160px・小さい表示領域では25%まで。長文・全画面編集を維持。HOME小カードの矢印をアイコンと分離。
- Worker候補側：サーバー受信時刻を実時計の基準、端末送信時刻を申告値、履歴日時を保存済み日時として区別。実時間だけでRP時間や場面を補完しない。通常のCOMMSに時刻説明を追加しない指示。日時の形式・暦日を検証。
- mainには画面側とアセットキャッシュ名の更新だけを反映。Workerや連携設定はmainへ追加しない。準備ブランチにはWorker候補だけを反映し、既存Builds設定による候補版作成を起動する。本番Workerへの切替は別操作・別承認。

## 検証と限界

Node 24.19.0、Wrangler 4.151.3。固定時計の16テストでJST日付・年境界・閏日・過去履歴・不正な端末時刻を検査。上流モデルはモックで、実モデルの順守は未検証。

Chromium/Playwrightで320×568、375×667、390×844、768×1024、1280×900を検証。4000文字、復元済み下書き、全画面入力、繰り返しナビゲーション、通信失敗時の保持、短縮viewportを確認。実機iPhoneのキーボード・IME・OS中断は未検証。

キャッシュ更新はアセット用Cache Storageの名前だけを変更。保管庫のlocalStorage・IndexedDB・鍵・保存形式は変更しない。既に開いている画面は再読み込み／開き直しが必要な場合がある。ストレージ消去や再インストールを更新手順にしない。

共通フォーマッターによりBACKSTAGEと通知の最終同期表示もJSTになる。通知処理・Cron・KV・Secrets・認証・料金・依存設定は変更しない。タイムゾーンのない旧保存日時があれば、その解釈は従来のDate解析に依存する。現在のISO保存形式を移行しない。

GitHubへの反映、Pagesでの公開、Worker候補版作成、本番Workerの稼働版は別の状態として確認する。この資料自体はデプロイ成功の証明ではない。本番HTTP試験・KV操作は行わない。

## データを消さないロールバック

画面側を戻す場合は本変更コミットを差し戻し、以前と異なる新しいアセットキャッシュ名で再公開する。localStorage・IndexedDB・保管庫・鍵は触らない。Worker候補は本番へ昇格しなければ本番に影響しない。将来本番へ昇格後に戻す場合は、承認のうえ既知の正常Worker版へ戻す。コードのロールバックでKVデータが戻るとは扱わない。
