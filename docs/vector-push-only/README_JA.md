# 一般文面のテストPush専用

push-test-onlyモードでは通知のAI判断・定期生成・通常ON・RP文脈同期を拒否します。Cron設定は0 * * * *のままです。通常chat機能は変更しません。

対応画面の「テスト通知を1件送る（専用モード・RP同期なし）」から、操作元確認済みの本人端末で通知許可・購読登録・一般文面1回を試行します。RP本文・資料はこの経路へ送信しません。通知許可のため再クリック案内が出た段階では、まだ送信していません。

DOと端末の試行記録は、停止・復旧・再起動でも消しません。成功・拒否・準備失敗・送信前中止・結果不明のいずれでも、この専用試験を再送しません。配信事業者の受付は端末表示の保証ではなく、受付後のPushは撤回できません。将来の再試験には明示的な別対応が必要です。

ローカルSQLite DOでモデル呼出しゼロ、重複/停止競合/再起動/応答消失、本文・受領印保持を検証。実ブラウザー7ケースと保存・復旧・共有文脈・サイズ境界・キャッシュ回帰も通過。実Pushと実機表示は別途確認します。

## Worker候補と復帰

既存のVECTOR_NOTIFICATIONSクラス・SQLite migration tag・VECTOR_KV・Secrets・暗号化・上限・Cronを維持。新migrationは追加しません。既定wrangler.jsoncはpush-test-only設定で、既存Buildsのversions uploadは候補を作成するためのものです。Build成功だけでは本番適用完了とは扱いません。

対応フロントの実端末更新と正しい候補versionを確認してから、本番へ適用します。activeは使用しません。テスト後は同じコード・DOを保持し、VECTOR_NOTIFICATION_MODEをmigration-stopへ戻します。設定変更の本番適用結果も確認してください。通常の旧WorkerへのRollback、DO/未読/試行記録の削除は行いません。既定設定はテスト専用のため、将来の候補を適用する際もmodeを再確認します。

現時点の公開・実行状態は実際の配備結果で確認してください。この記録は成功した実Pushの証明ではありません。
