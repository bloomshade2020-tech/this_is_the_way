# 本文コピーと通知アイコン参照の更新

HERE・COMMS・BACKSTAGEの各メッセージに本文コピーを追加。日時・話者・ID・写真を含めず、本文の改行と空白を保持します。Clipboard APIが拒否された場合や利用できない場合は、読み上げ対応の案内を表示し、本文の手動選択が可能です。

通知アイコンはmanifestとApple用参照と同じ承認済みAの版付きURLに統一しました。アセットキャッシュ名も更新します。暗号化保管庫や履歴は変更しません。iOSのインストール済みアイコンや通知表示が直ちに更新されることは保証しません。再インストール・データ消去は不要です。

HERE配色は変更していません。基準コードと更新コードで朝・昼・夕・夜の4色の切替をローカル確認しましたが、実機の「全てデフォルト」は未再現です。RP時刻の意味や通知生成には変更がありません。

検証: コピー3画面幅・3部屋・両話者、長文/改行/空白、キーボード、拒否/API非対応、繰り返し移動・待機中移動・下書き保持を合成データで確認。模擬Service WorkerでアイコンURL・一般文面・クリック先を検証。既存UI5サイズ、保管庫4サイズ、共有文脈11項目、保存競合、キャッシュ、構文チェック通過。実通知・AI呼出しは行っていません。

iPhoneでのClipboard権限と旧アイコン更新は実機確認が必要です。Worker・Cloudflare設定・通知停止状態は対象外です。

取り消す場合はこの変更の実装ファイルを元に戻し、公開時に別のアセットキャッシュ名を使用します。保管庫・履歴・IndexedDB・localStorageは削除しません。
