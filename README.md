# DIN // COMMS — UI Prototype v0.2

v0.1 の端末デザインを保持し、通信画面をメッセージアプリ風に更新しました。

## v0.2 でできること
- ディンと自分の通信を左右の吹き出しで表示（日時と日付区切りつき）
- 「＋」から既存のChatGPT通信を **手動で記録**。日時も指定可能
- 返信の下書き、コピー、**端末内の記録**。本物の送信はしません
- 設定に保存した「通知部屋」のURLを開ける
- 記録のない状態でも「SAMPLE」と明示したデモ吹き出しを表示
- 既存のロック画面・ホーム・RP・外・端末内保存・JSONバックアップを維持

## まだできないこと
- ChatGPTのRPやタスクから自動でデータを取得すること
- アプリからディンへ送信すること
- プッシュ通知、バックグラウンド判定、端末間同期

**注意:** 本アプリは表示確認用のローカルUIです。通信データはこの端末にのみ保存され、ChatGPTの本編やタスクは変更しません。重要なRP記録の唯一の保管先にはしないでください。公開のGitHubリポジトリに生ログ・設定資料・APIキーを追加しないでください。

## GitHub Pages で v0.1 から更新する
1. ZIPを展開し、その中の `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `README.md` を全部選ぶ
2. 今使っている `this_is_the_way` リポジトリで `Add file → Upload files` にドラッグ＆ドロップ
3. 既存ファイルの置換を確認して `Commit changes` する（リポジトリ設定の Pages はそのままでOK）
4. 公開処理の完了後、iPhoneの `DIN COMMS` を閉じて開き直す。画面が古ければ少し待って再起動
5. ロック解除→「通信」→右上「＋」からメッセージを試す

なお、更新しても既存の記録は **同じ端末・同じホーム画面アプリの保存領域が維持される限り** 引き継がれます。念のため、更新前に「設定」からJSONバックアップもできます。

この非公式UI試作はStar WarsまたはOpenAIの公式アプリではありません。
