# DIN // COMMS — UI Prototype v0.1

「This is the way」専用端末の**見た目と操作感を試すため**の静的Webアプリです。

## 実装済み
- 架空のロック画面（タップ／上スワイプで解除）
- ホーム画面（通信・RPへ移動）
- 通信履歴の手動登録／表示
- RP本文風のローカル記録（自分の文章と、手動で貼り付けたディンの文章）
- RPと分離した「外」メモ画面
- 既存ChatGPTのRP部屋・通知部屋へのリンク登録
- ブラウザ内保存、データのJSON書き出し
- ホーム画面への追加に対応するPWA設定

## 未実装（重要）
- ChatGPTの既存RP部屋との自動連携・送受信
- 今の通知タスクの自動取り込み
- 実際のプッシュ通知
- OpenAI APIへの接続
- 複数端末間の同期

入力した文章は**利用しているブラウザのlocalStorage**に保存されます。履歴の喪失を避けるため、正式なRPログとして使用しないでください。ブラウザのローカル保存領域にデータがあるため、他の人と共用する端末ではご注意ください。

## Windowsでまず試す
1. ZIPを展開
2. `index.html` をChromeで開く
3. 「上にスワイプ / タップして解除」でホームに入る
4. 通信を手動追加して外見を確認する

## GitHub PagesでiPhoneから試す
1. GitHubに**試作用の新しいリポジトリ**を作成（Web上で誰でも見られる公開リポジトリでは、**コードを公開することになる**）。このアプリには秘密の設定／RPの生ログ／APIキーをアップロードしないこと。
2. ZIP内の `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` をリポジトリのルートにアップロード
3. リポジトリの Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` → Save
4. 表示された `https://ユーザー名.github.io/リポジトリ名/` へ、iPhoneのSafariでアクセス
5. Safariの共有メニュー → 「ホーム画面に追加」で端末アイコンから起動できる

※GitHub Pagesには発行まで少し時間がかかる場合があります。無料アカウントの場合、GitHub Pagesでの公開には公開リポジトリが必要な場合があります。
※GitHub Pagesの公開URLが第三者に見えても、このアプリはサーバーに入力内容を送信しません。ただしブラウザ内保存は絶対的な秘密保護を意味しません。
※プッシュ通知を使うには、後から通知配信用の別の実装が必要です。
